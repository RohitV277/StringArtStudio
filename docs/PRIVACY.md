# Privacy

- No account, no analytics, no ads, no tracking.
- The app makes no network requests while you use it. The only requests are the first download of the app files and later update checks for the offline cache.
- Designs and saved projects are stored in the device's own storage. Clearing the browser's site data or deleting the app removes them. Use **Save project file** to keep a backup.
- Text you type is turned into outlines on the device. It is never sent anywhere.
- The Content Security Policy blocks connections to other sites.
